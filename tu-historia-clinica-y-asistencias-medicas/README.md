# Tu Historia Clínica y Asistencias Médicas

Dispones de acceso a la información de tu [Historia Clínica](https://soporte-ibermutua-digital.scroll.site/soporte-ibermutua-digital/glosario) y toda tu Asistencia Médica dentro de [Ibermutua Digital Personas](https://personas.ibermutua.es/).

{% hint style="info" %}
La [**Historia Clínica**](https://soporte-ibermutua-digital.scroll.site/soporte-ibermutua-digital/glosario) es el archivo de todos los procesos asistenciales producidos entre la mutua y el paciente. Se organiza por **Episodios Médicos** (cada cual con su diagnóstico, fecha de la baja y duración total).
{% endhint %}

Desde aquí, podrás consultar datos sobre tus bajas laborales, ver pruebas diagnósticas, descargar informes y gestionar tus citas.

* [Consulta de Citas Pendientes](consulta-de-citas-pendientes.md)

* [Consulta del histórico de Episodios Médicos](consulta-del-historico-de-episodios-medicos.md)

* [Generación y descarga del informe de Tu Historia Clínica](generacion-y-descarga-del-informe-de-tu-historia-clinica.md)

* [Visualización de Pruebas Diagnósticas](visualizacion-de-pruebas-diagnosticas.md)

* [Solicitud de Segunda Opinión Médica](solicitud-de-segunda-opinion-medica.md)

* [Consulta y Acceso a Documentación Administrativa](consulta-y-acceso-a-documentacion-administrativa.md)

* [Justificantes de Asistencia](justificantes-de-asistencia.md)

{% hint style="info" %}
La **historia clínica, informes y pruebas diagnósticas** constituyen datos de salud especialmente protegidos. Para garantizar un acceso seguro, recuerde **no compartir sus credenciales de usuario y cerrar la sesión al finalizar** la consulta.
{% endhint %}
