# Consultar la documentación de una baja

{% hint style="warning" %}
Página de prueba con contenido ficticio.
{% endhint %}

Como empresa, puedes consultar los partes y documentos de la baja de una persona trabajadora.

1. En el menú, pulsa **Bajas**.
2. Abre la baja que quieres consultar.
3. En **Documentación**, pulsa el documento para verlo o descargarlo.
