---
title: Para qué es el chat
---

{% hint style="warning" %}
**El chat es solo para dudas médicas sobre tu proceso**, como síntomas, tratamiento, pruebas o seguimiento. Cada conversación está ligada a un episodio médico. No lo uses para urgencias, ni para prestaciones económicas o gestiones administrativas. Se responde en horario laboral, lo antes posible, pero no al momento. El uso indebido puede suponer su cierre.
{% endhint %}
