# Solicitar una segunda opinión médica

Puedes solicitar una segunda opinión médica online, desde un episodio de tu historia clínica, o en persona en cualquier [centro de Ibermutua](https://www.ibermutua.es/red-de-centros/). Online, la solicitud se hace en dos pasos y te contactarán en un plazo de 3 a 10 días.

<figure><img src="../.gitbook/assets/c73acdb96fb9-Image_boefqzboefqzboef.webp" alt="Pantalla Solicitar segunda opinión médica en web y móvil, con las ventajas del servicio, el campo opcional Cuéntanos por qué y el botón Enviar solicitud."><figcaption><p>Solicitud de segunda opinión médica en web y en el móvil.</p></figcaption></figure>

{% tabs %}
{% tab title="Web" %}
{% stepper %}
{% step %}
### Abre la solicitud desde el episodio <a href="#segunda-opinion-acceder" id="segunda-opinion-acceder"></a>

En **Historia clínica > General**, abre el episodio. A la derecha, pulsa **Segunda opinión médica**.

<figure><img src="../.gitbook/assets/78419a80c620-image-20260504-105036.webp" alt="Web, ficha de un episodio médico con la opción Segunda opinión médica señalada en Tus gestiones digitales."><figcaption><p>Segunda opinión médica, a la derecha del episodio.</p></figcaption></figure>
{% endstep %}

{% step %}
### Envía la solicitud <a href="#segunda-opinion-enviar" id="segunda-opinion-enviar"></a>

El episodio ya aparece seleccionado. Si quieres, cuéntanos por qué pides la segunda opinión. Pulsa **Enviar solicitud**.

<figure><img src="../.gitbook/assets/ac3a582979fa-image-20260504-105637.webp" alt="Web, formulario Solicitar segunda opinión médica con el episodio seleccionado, el campo opcional Cuéntanos por qué y el botón Enviar solicitud."><figcaption><p>Formulario de solicitud.</p></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="App" %}
{% stepper %}
{% step %}
### Abre la solicitud desde el episodio <a href="#segunda-opinion-acceder-app" id="segunda-opinion-acceder-app"></a>

En **H. Clínica**, pulsa el episodio médico. Después, pulsa **Mostrar más acciones** y elige **2ª Opinión Médica**.

<figure><img src="../.gitbook/assets/154864594600-image-20260209-093435.webp" alt="App móvil, ficha de un episodio con el menú Mostrar más acciones abierto y la opción 2ª Opinión Médica resaltada."><figcaption><p>Mostrar más acciones > 2ª Opinión Médica.</p></figcaption></figure>
{% endstep %}

{% step %}
### Envía la solicitud <a href="#segunda-opinion-enviar-app" id="segunda-opinion-enviar-app"></a>

Selecciona el episodio. Si quieres, explica el motivo de tu solicitud. Pulsa **Enviar solicitud**.

<figure><img src="../.gitbook/assets/319d35f3d593-image-20260204-135256.webp" alt="App móvil, formulario Segunda opinión médica con el episodio seleccionado, el campo Motivo de tu solicitud (opcional) y el botón Enviar solicitud."><figcaption><p>Formulario de solicitud en la app.</p></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}
{% endtabs %}

{% hint style="success" %}
**Al terminar** verás la confirmación de la solicitud. Te contactarán en un plazo de 3 a 10 días.
{% endhint %}

<figure><img src="../.gitbook/assets/a63d246a4e40-image-20260729-060252.webp" alt="Confirmación en web y móvil de la solicitud realizada, con el aviso del plazo de contacto."><figcaption><p>Confirmación de la solicitud.</p></figcaption></figure>
