# Ver tus pruebas diagnósticas

Puedes ver todas las pruebas diagnósticas que te ha hecho Ibermutua o solo las de un episodio médico. Las pruebas de imagen se abren en un visor especial. Si no ves una prueba reciente, consulta [cuándo están disponibles](../preguntas-frecuentes/cuando-estan-disponibles-las-pruebas.md).

## Ver todas tus pruebas <a href="#pruebas-todas" id="pruebas-todas"></a>

{% tabs %}
{% tab title="Web" %}
En el menú superior, pulsa **Historia clínica** y elige **Pruebas médicas**. Se abre la pestaña **Pruebas y documentos** con todas tus pruebas.

<figure><img src="../.gitbook/assets/9642bf56e336-menu-pruebas-recorte.webp" alt="Menú Historia clínica desplegado con la opción Pruebas médicas señalada."></figure>
{% endtab %}

{% tab title="App" %}
En **H. Clínica**, pulsa la pestaña **Pruebas y documentos**. Puedes filtrar por tipo, episodio, fecha y quién lo ha subido.

<figure><img width="300" src="../.gitbook/assets/42f24068e292-pruebas-documentos-app-recorte.webp" alt="Pestaña Pruebas y documentos de la app resaltada, con los filtros Tipo, Episodio, Fecha y Subido."></figure>
{% endtab %}
{% endtabs %}

## Ver las pruebas de un episodio <a href="#pruebas-episodio" id="pruebas-episodio"></a>

{% tabs %}
{% tab title="Web" %}
[Abre el episodio médico en tu historia clínica](consultar-tu-historia-clinica.md#historia-abrir). En **Histórico de actividad**, pulsa el filtro **Pruebas médicas**.

<figure><img src="../.gitbook/assets/0fe3d3dd7073-filtro-pruebas-recorte.webp" alt="Histórico de actividad de un episodio con el filtro Pruebas médicas señalado y una resonancia magnética en el listado."></figure>
{% endtab %}

{% tab title="App" %}
En **H. Clínica**, [abre el episodio médico](consultar-tu-historia-clinica.md#historia-abrir) y consulta sus pruebas en **Pruebas y documentos**.
{% endtab %}
{% endtabs %}

## Ver una prueba de imagen <a href="#pruebas-visor" id="pruebas-visor"></a>

Las pruebas de imagen (radiografía, resonancia magnética, TAC…) se abren en un visor especial que permite verlas con detalle.

<figure><img src="../.gitbook/assets/c459092e33f7-Rodilla-gif.webp" alt="Animación del visor de pruebas de imagen: radiografía de rodilla en proyecciones frontal y lateral, con la barra de herramientas del visor arriba."></figure>
