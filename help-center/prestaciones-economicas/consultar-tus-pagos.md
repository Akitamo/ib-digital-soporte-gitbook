# Consultar tus pagos

En **Pagos** ves el estado de abono de todas tus prestaciones económicas, también las de pago directo, y puedes descargar el detalle de cada una.

## Consulta tus pagos <a href="#pagos-consultar" id="pagos-consultar"></a>

{% stepper %}
{% step %}
### Abre Pagos

En el menú superior, pulsa **Prestaciones económicas** > **Pagos**.

<figure><img src="../.gitbook/assets/9e5f5f992ca2-menu-prestaciones-economicas-recorte.webp" alt="Menú Prestaciones económicas abierto con las opciones Solicitudes, Pagos, Autopagos y Certificados de retenciones."></figure>
{% endstep %}

{% step %}
### Abre una prestación

Pulsa una prestación para ver el detalle de sus pagos: fecha y periodo, total, estado, importe base y retenciones.
{% endstep %}

{% step %}
### Descarga el detalle, si lo necesitas

Pulsa **Descargar como Excel**.

<figure><img src="../.gitbook/assets/0c6fca1e443b-descargar-excel-recorte.webp" alt="Detalle de una prestación económica con el total, el botón Descargar como Excel señalado y la tabla de pagos con fecha, total, estado, importe base y retenciones."></figure>
{% endstep %}
{% endstepper %}

## Estados del pago <a href="#pagos-estados" id="pagos-estados"></a>

En la columna **Estado** verás:

* **Autorizado pendiente de pago**: el pago está aprobado y preparado para salir.
* **Transferencia realizada**: el dinero ya se ha enviado a tu banco.
