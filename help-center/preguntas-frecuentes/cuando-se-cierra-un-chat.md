# ¿Cuándo se cierra un chat?

Cuando termina el episodio médico al que está ligado o si se hace un uso indebido de él. A partir de ese momento no puedes escribir mensajes nuevos.

## Si tu chat está cerrado <a href="#chat-cerrado" id="chat-cerrado"></a>

Puedes seguir consultando el historial de mensajes. Para contactar con nosotros, usa la sección de ayuda o llama al <code class="expression">space.vars.telefono_atencion</code>.
